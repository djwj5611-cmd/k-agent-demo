비즈니스 상태는 잘못 바뀌었다면?

K-Agent는 tool-using AI 에이전트의 최종 비즈니스 상태(환불·취소·주문·예약)를 결정론적으로 검증합니다. 응답 품질이 아니라 실제 결과를 검사합니다.

실패 예시 (합성 데모)

고객 요청: "배송 시작된 건 두고, 준비 중인 상품만 취소해줘"

agent → cancel_order(order_id="A-1024", items="ALL") result: 주문 전체 취소됨 · 배송 중 상품 포함

✗ K-Agent 판정: WRONG_TERMINAL_STATE — 부분 취소 실패, 배송 중 상품까지 취소됨 (출고 후 취소 불가 조건 위반)

수정 후 재실행
agent → cancel_order(order_id="A-1024", items=["B-2201"], condition="status==preparing") result: 준비 중 1개 상품만 취소 · 배송 중 상품 유지

✓ K-Agent 판정: PASS — REFUNDED, 조건부 부분 취소 정상 종료
